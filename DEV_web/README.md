## Pokeon

Application front-end permettant de consulter des informations sur les Pokémons.

- Recherche d'un Pokémon par numéro
- Liste filtrée par génération
- Détail des baies avec image et statistiques
- Comparateur de stats entre deux Pokémons
- Lecture des cris audio

Aucune installation requise — ouvrir `Pokeon/pokemon.html` directement dans le navigateur.

---

## Guerre des Animaux

Application fullstack de gestion d'armées d'animaux.

- Backend : Python / Django REST Framework
- Frontend : HTML / CSS / JavaScript vanilla
- Authentification par token
- Chaque utilisateur gère son armée, ses animaux et leurs armes

Voir `guerre_animaux/guerre_animaux/README.md` pour les instructions d'installation.
